# 正式信号效果追踪

这里只描述采样研究，不代表交易执行、可成交收益或已验证的盈利策略。

## 前瞻记录

`signal_research` 只在新产生的 `CONFIRMATION / CONFIRMED` 事件入库时注册。主键 `signal_id` 防重复，另保存 chain、token、pool、触发 UTC、来源时间、基准价、基准流动性、规则与版本、配置指纹、因子和完整公开行情证据快照。WATCH、数据故障和旧版历史不会被包装成正式样本。

每个信号分别跟踪 1h、2h、6h，不使用首次发现价代替信号基准。原 V1 首次观察研究保留作为独立历史功能。

## 时点与数据质量

默认目标容差为 ±180 秒，可用 `outcome_tolerance_seconds` 调整（1–300 秒）。只选择目标容差内、已实际观测且有正价格的最近样本；距离相同优先较早样本。容差未结束前不冻结收益。不得使用未来记录、远期价格或插值补齐。

| 状态 | 含义 |
|---|---|
| PENDING | 目标时间及容差尚未结束，收益保持 null |
| COMPLETE | 目标附近有有效样本，同源采样连续且最大间隔不超过配置值 |
| MISSING | 目标容差内没有有效价格，保留记录，不按归零处理 |
| CENSORED | 终点存在，但中途缺口、源切换或无效价格使完整结果不可核验 |

每个窗口在到期后第一次评估时冻结；晚到或恢复导入的数据不会重写已冻结结果。断网、休眠、预算未覆盖和市场数据不再可得均可能造成缺失。源切换保守标记为删失，避免把不同聚合器的时间/价格误差当收益。

## 指标

- `return_pct`：目标附近实际价格相对信号基准的变化。
- `max_positive_pct` / `max_negative_pct`：已观测价格相对基准的最大正向 / 负向变化，包含基准 0。
- `max_drawdown_pct`：已观测路径峰值到后续低点的最大回撤，不与基准亏损混同。
- `liquidity_change_pct`：目标附近流动性相对基准变化；未知则 null。
- `invalidated`：窗口内是否出现对应池的结构失效事件。
- `samples`、`max_gap_seconds`、`observed_at`、`source_changed`：可核验的数据质量证据。

这些极值只覆盖实际采样点，无法代表两次采样之间的真实最高/最低价；未扣除手续费、滑点，不保证可成交。

## 统计与导出

按规则、版本和窗口分组，展示触发数、到期数、有效数、MISSING、CENSORED、PENDING，以及有效样本的平均/中位收益和负/平/正分布。平样本定义为收益绝对值 ≤0.1%。

缺失率 = `(MISSING + CENSORED) / 已到期窗口数`；PENDING 尚未进入到期分母，但保留在总触发记录。默认每组有效样本少于 30 时为 `INSUFFICIENT_SAMPLE`，足量也只标 `DESCRIPTIVE_ONLY`，从不宣称存在稳定盈利 Edge。重复信号可能来自同一池，样本非相互独立。

本地 `/api/research` 和快照 `research` 使用相同契约。Vue 研究页可导出 CSV/JSON，采用字段白名单；不会导出 Telegram 配置或整个数据库。公开 Pages 从新建临时数据库扫描，通常没有成熟前瞻信号，空研究报告是实际能力边界。
