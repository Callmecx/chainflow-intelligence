# V1.1 封版边界

项目定位为 Rust / Web3 求职作品，完成核心验收后标记 PORTFOLIO_READY，不再自动规划 V1.2、V2 或商业平台扩张。

- 真实行情：SOL/BSC DEX Screener 与 GeckoTerminal 公开接口；存在收录、推广、缓存和覆盖偏差。不是全网新币扫描器。
- RPC：只读 WSOL/BSC 基准账户、chainId/区块/eth_call；不是全链交易解码器。BSC event logs 保持 UNSUPPORTED，未接付费 RPC。
- 结构：基于同源 SAMPLED 点；默认采样无法确认 3m 细粒度形态，未把采样曲线包装成原始 K 线。5m/15m 不足或断档时不确认。
- 评分：可配置因子权重和条件覆盖分，不是上涨概率。滚动 5m 买卖笔数有窗口重叠，不代表净资金流；24h 量变化不冒充独立短时成交量。
- 风险：流动性变化、价格变化和结构失效依赖来源数据。市场风险与数据故障分离；honeypot、Top10、聪明钱均 UNKNOWN。
- 通知：SQLite 去重、优先级、冷却、重试、429 处理和重启恢复已实现；网络超时为 UNCERTAIN，不自动重发，无法 Exactly Once。未配置真实凭据时 Telegram 实投为 PENDING，Mock 不算实投。
- 研究：只注册升级后新产生的正式信号；旧历史不补造规则结果。缺失/删失保留分母，自然样本不足显示 INSUFFICIENT_SAMPLE，无盈利承诺。
- 可靠性：短 Canary 不是高可用或长期性能证明。6h/24h 脚本可由用户独立启动，未执行/未完成时为 PENDING；按最新封版范围，长跑不作为作品发布硬门槛。
- 本地边界：回环服务适合单人本机使用，不提供公网多租户、认证或商业 SLA。休眠/断电会造成缺口。
- Pages：目标半小时快照，调度可能延迟。静态页不托管持续 Rust 服务，不公开私人观察名单、SQLite 或通知配置。
- 归档：继续使用单 writer 归档，运行中日志按启动分段；没有宣称完成长期归档周期或全年日志治理。

本轮无付费 API、托管、订阅、自动交易、私钥访问、AI 预测或大型分布式组件。实际测试与当前 PENDING 项统一列于 [V1_1_ACCEPTANCE.md](V1_1_ACCEPTANCE.md)。
